# 设定一致性 · Lore Compliance Skill

引用已有设定时保持一致；创作新设定时区分“已经成立的事实”和“正在提出的方案”。一致性服务于创作连续性，不阻止新内容生长。

---

## 已确认设定是当前基线

通过 `search_lore`、`read_lore_entry` 和 `read_file` 获取当前已经成立的设定。标记为 `confirmed` 的条目是续写基线；`draft` 可以继续讨论和调整；`deprecated` 只用于理解历史版本。

- **数值绝对一致**：时间数值、修为等级、人物年龄/关系时长必须严格遵循记录。
- **关系绝对准确**：情感定位必须符合记录中的性格和人际关系设定。禁止添加不存在的关系。
- **物品绝对匹配**：装备名称和特征必须准确，禁止虚构物品。
- **地点保持连续**：复用已确认的名称、空间关系和稳定特征。
- **称号绝对严格**：只使用确切记载的称号。

## 缺失设定的处理

如果当前情节需要一个尚未记录的设定：
1. 先用 `search_lore` 搜索关键词
2. 不影响因果的局部细节可以自然完成，不必全部落盘
3. 会反复使用或改变情节因果的内容，提出简洁方案并标为 `draft`
4. 用户确认或认可相关正文后，再更新为 `confirmed`

不要把模型临时补出的内容伪装成早已存在的设定，也不要因为设定库暂时没有记录就让所有创作停摆。

## 时间线一致性

- 叙述中的时间跨度（"三年前"、"四十年前"）必须与角色设定中的年龄/经历吻合
- 季节、天气、时辰如果在前文提及过，后续必须保持一致
- 重生文特别注意：前世与今世的时间点必须严格区分，不可混淆

## 人物连续性

角色的稳定属性发生变化时，需要有剧情原因并更新设定，而不是无意漂移：
- 说话方式（口癖、用词习惯、语气）
- 性格核心特征
- 已知的人际关系
- 能力上限（不可突然"爆种"超过设定上限）

## 执行清单

1. [ ] 我引用的每个人名、地名、物品名都能在设定中找到出处吗？
2. [ ] 我写的时间线与角色年龄/经历吻合吗？
3. [ ] 角色的说话方式与设定中的性格匹配吗？
4. [ ] 新出现的内容是局部细节、候选设定还是稳定事实？
